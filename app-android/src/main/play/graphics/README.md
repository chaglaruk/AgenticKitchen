# Google Play graphics

Place final Play Store assets under the locale-specific listing folders using Gradle Play Publisher's supported structure:

- `listings/en-GB/graphics/icon/1.png` — 512x512
- `listings/en-GB/graphics/feature-graphic/1.png` — 1024x500
- `listings/en-GB/graphics/phone-screenshots/1.png` ... `8.png`

Mirror or localize assets under `tr-TR` only when the visual itself contains language-specific text.

Do not commit placeholder or roadmap-only screenshots. Store screenshots must reflect a build appropriate to the advertised verification state.
